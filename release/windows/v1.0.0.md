## antwork v1.0.0 for Windows

Download **antwork-1.0.0-Setup.exe** below and run it on Windows x64.

### Installation

- Choose installation for your current Windows user or everyone. Installing for everyone requests administrator access.
- Choose the installation folder and follow the wizard's progress page.
- Electron is bundled, so you do not need Node.js or a development server. The app works offline.

### Included

- Dashboard, Timers, Calendar, Work Hours, and career statistics.
- A movable, resizable pop-out timer synchronized with the main window.
- Custom title bars, window controls, timer backgrounds, and translucent timer controls.
- Timers continue while minimized or the screen is locked; sleep and quitting pause them.
- Local history and JSON backup export/import. History is preserved after uninstall.

### Before installing

This release is **unsigned**. Windows may show an unknown-publisher warning or block it under your security policy.

If upgrading from a 0.1.x desktop build, export a JSON backup, close antwork, and uninstall the old version through Windows Settings first. Your history remains under `%APPDATA%\antwork`; the new installer uses a different installation location. Importing a backup replaces the destination history.

### Validation and known issues

The build and all 67 unit tests passed. Packaged checks passed offline launch, screen navigation, renderer isolation, minimize and lock behavior, sleep pause, manual resume, session saving, and JSON transfer.

The full automated desktop test timed out waiting for the app to exit after clicking its Close button. This check remains unresolved. Both installer scopes still need a clean-machine walkthrough. Windows 11 x64 is the primary target; Windows 10 compatibility has not been verified on Windows 10.
