# antwork v1.1.0 for Windows

**Refreshed October 10, 2026.** This replaces the original v1.1.0 installer and release notes, keeping the same version and release tag. If you already installed v1.1.0, download and run the replacement installer to get shared day-card backgrounds.

## Worked-day achievement cards

Open **Calendar**, select today or a past date with saved work, and choose **View day card**. See the date, combined saved hours, and your existing **Good**, **Steady**, **Rough**, or **Unrated** day quality. Unfinished timer time is excluded; the card does not change Score.

- Save up to two pictures or videos through **Day-card backgrounds** in Calendar or a day card. Select one background and it applies to every day card.
- Cards start without media. **No background** hides both saved choices. Removing the selected choice uses the remaining background, or leaves the card blank.
- Save applies the draft; Cancel or Escape discards it. Calendar's editor is available even without saved work, so backgrounds can always be removed.
- Older per-date backgrounds remain intact until you confirm **Replace all older per-date backgrounds**. The editor offers JSON export first; Cancel and failed saves preserve the older collection.
- Pictures accept PNG, JPEG, or WebP up to 10 MiB and use the timer's local WebP processing.
- Videos accept playable MP4 or WebM clips up to 5 MiB and 30 seconds. They loop automatically and silently while visible, with no playback controls. Hidden or closed cards stop playback.
- The popup is transparent. Text shadows keep the card readable, and day quality appears without a border or badge fill.
- Pictures and videos travel with JSON backups. Rejected uploads or failed saves retain saved history and the current draft.

This release also fixes the Close-button crash caused by a late timer update reaching a destroyed window. Desktop builds now use `app-dist/` separately from the website's `dist/`; the website remains the app download page.

## Updating and backups

Export a backup and close antwork before running `antwork-1.1.0-Setup.exe`, including when replacing an already installed v1.1.0 build. Updates retain the same `%APPDATA%\antwork` profile. If upgrading from a 0.1.x Squirrel build, uninstall that old version through Windows Settings first; uninstalling preserves the data profile.

Current backups use schema version 7. This refreshed v1.1.0 build imports versions 1 through 7, preserving older history and every older per-date background. Both shared choices are included in exports. **v1.0.0 and the original v1.1.0 build cannot import schema-7 backups.** Importing replaces destination history, so export it first if needed.

The backup limit is 32 MiB. Changes that grow a document beyond that limit are rejected without losing saved history or the draft. Remove stored backgrounds to free space. The Windows app works offline; media and work history stay on your computer until exported.
