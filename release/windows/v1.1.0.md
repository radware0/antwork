# antwork v1.1.0 for Windows

## Worked-day achievement cards

Open **Calendar**, select today or a past date with saved work, and choose **View day card**. See the date, combined saved hours, and your existing **Good**, **Steady**, **Rough**, or **Unrated** day quality. Unfinished timer time is excluded; the card does not change Score.

- Add, replace, or remove one picture or video background per date.
- Pictures accept PNG, JPEG, or WebP up to 10 MiB and use the timer's local WebP processing.
- Videos accept playable MP4 or WebM clips up to 5 MiB and 30 seconds. They loop automatically and silently while visible, with no playback controls. Hidden or closed cards stop playback.
- The popup is transparent. Text shadows keep the card readable, and day quality appears without a border or badge fill.
- Pictures and videos travel with JSON backups. Rejected uploads or failed saves retain saved history and the current draft.

This release also fixes the Close-button crash caused by a late timer update reaching a destroyed window. Desktop builds now use `app-dist/` separately from the website's `dist/`; the website remains the app download page.

## Updating and backups

Export a backup and close antwork before running `antwork-1.1.0-Setup.exe`. Updates retain the same `%APPDATA%\antwork` profile. If upgrading from a 0.1.x Squirrel build, uninstall that old version through Windows Settings first; uninstalling preserves the data profile.

Current backups use schema version 6. v1.1.0 imports versions 1 through 6, preserving older history and adding empty card-background defaults. **v1.0.0 cannot import schema-6 backups.** Importing replaces destination history, so export it first if needed.

The backup limit is 32 MiB. Changes that grow a document beyond that limit are rejected without losing saved history or the draft. Remove stored day backgrounds to free space. The Windows app works offline; media and work history stay on your computer until exported.

## Validation and test limits

- 71 unit tests passed with zero failures.
- Production website and desktop builds passed. Website checks cover the download page, both themes, responsive layouts, preserved browser history, and Docs theme synchronization.
- Packaged day-card checks passed for saved hours, all day ratings, image drafts, MP4/WebM silent loops without controls, visibility, both themes, narrow windows, invalid uploads, backup round trips, failed writes, size limits, and temporary URL cleanup. Videos continue looping when reduced motion is enabled, as requested during the screenshot review.
- Packaged desktop checks passed for offline navigation and Docs, timer synchronization, tray and pop-out behavior, native JSON transfer, sleep-event pause, close/reopen, and crash recovery.
- A real v1.0.0 packaged app and v1.1.0 used the same isolated profile successfully. Hours, journals, ratings, identity data, images, settings, campaigns, and the paused timer were preserved. This tests application migration, not installer replacement.

Tested on Windows 11 Pro x64. **This installer is unsigned.** Windows security may warn or block it. Windows 10, clean-machine NSIS walkthroughs for both install scopes, actual installer replacement, physical sleep, Narrator, and multi-monitor scaling remain untested. Earlier Squirrel installation checks do not establish NSIS installer coverage.
