# The daily loop

antwork is meant to be usable before you have a perfect plan. A stopwatch starts from Dashboard in one click. The Dashboard calendar is view-only; open Calendar when you want to inspect or edit a day.

## Lock in

**Start lock-in** begins an unlinked stopwatch. Timers also offers a countdown from 1 minute to 12 hours, entered as hours and minutes. You can pause and resume either mode. The timer uses persisted timestamps, so a refresh or sleeping computer does not reset its elapsed time. A countdown stops at its deadline and opens a session review when the app can settle it.

The review is where you may connect the session to a campaign, rate how it felt, or add a session note. None is required. The timer's unfinished time appears provisionally in today's display; career totals and Score include it only after it is saved.

## Record time another way

**Add work hours** on Calendar or Work Hours asks for a date, hours, and minutes. It saves a dated duration without inventing a start or end clock time. If exact times matter, choose **Use start and end times**. Corrections to an untouched endpoint retain its original seconds and milliseconds; an edited endpoint is saved to the selected minute.

## Reflect and review

The journal holds one private note per day. Saved text is readable on Dashboard and Calendar; **Edit** opens the note without altering it until Save changes succeeds. Calendar day detail shows the day's sessions and note. Work Hours shows a 30-day chart and a match-style history.

## Keep your own copy

Profile's **Local backup** exports the complete record as JSON. Import validates the file and asks before replacing local history. Backups include notes, profile images, and other personal content and are not encrypted. Store them accordingly. See [Data and privacy](/docs/privacy/).
